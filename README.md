# Simple Calculator

A command-line calculator built with Node.js.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Square Root
- Percentage
- Input validation
- Error handling

## Technologies

- JavaScript
- Node.js
- npm

## Project Structure

src/
├── calculator.js
├── operations.js
└── utils.js

## Installation

```bash
npm install
```
